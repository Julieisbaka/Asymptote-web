# API guide

This guide describes the public runtime API exported by `asymptote-web`.
For exact TypeScript interfaces, see the [type reference](../types.md).

- [Runtime and engine setup](runtime.md): initialization, asset URLs, and
  compiler diagnostics.
- [Rendering and browser integration](rendering.md): rendering, mounting,
  downloads, batches, WebGL, and errors.
- [PDF export](pdf.md): optional `asymptote-web/pdf` helpers.
- [EPS/PS conversion](conversion.md): standalone conversion and gradients.
- [Utility helpers](utilities.md): diagnostics, matrices, and colors.

The original [`docs/api.md`](../api.md) remains the stable entry point and
links here for compatibility.
